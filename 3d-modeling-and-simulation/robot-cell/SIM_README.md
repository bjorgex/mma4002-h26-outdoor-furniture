# Robot-cell simulator: install and run

Our own simulator for the bench assembly cell (Omron TM5-900 + Hand-E). It runs the robot program
and shows it live in 3D in your browser. It also checks for collisions.
**You do not need RoboDK** (no app, no licence). It is Python plus a web page, and it works on
Windows, macOS and Linux.

## 1. What you need

- **Python 3.11 or newer.** Check with `python --version` (on macOS: `python3 --version`).
  If you don't have it, get it from https://www.python.org/downloads/. On Windows, tick
  *"Add python.exe to PATH"* in the installer.
- **Git.** On Windows: https://git-scm.com/download/win. On macOS: run `xcode-select --install`.
- **A browser** (Chrome, Edge, Firefox, Safari) and an **internet connection**. The 3D view loads
  three.js from cdn.jsdelivr.net.
- Access to the GitHub repo `bjorgex/mma4002-h26-outdoor-furniture`. Ask Bjørge to add you as a
  collaborator if you can't open it.

## 2. Install (once)

### Windows (PowerShell)

```powershell
git clone https://github.com/bjorgex/mma4002-h26-outdoor-furniture.git
cd mma4002-h26-outdoor-furniture\3d-modeling-and-simulation\robot-cell
python -m venv .venv
.venv\Scripts\Activate.ps1
pip install -r requirements-sim.txt
```

If `Activate.ps1` fails with *"running scripts is disabled on this system"*, run this once, then
activate again:
`Set-ExecutionPolicy -Scope CurrentUser RemoteSigned`

### macOS / Linux (Terminal)

```bash
git clone https://github.com/bjorgex/mma4002-h26-outdoor-furniture.git
cd mma4002-h26-outdoor-furniture/3d-modeling-and-simulation/robot-cell
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements-sim.txt
```

Check that the install worked:

```
python -c "import numpy, scipy, trimesh, fcl, robodk; print('ok')"
```

It should print `ok`. If only `fcl` fails, see [Problems](#5-problems).

## 3. Run the simulation

Do every step from the `robot-cell` folder, with the venv active. Your prompt starts with `(.venv)`
when it is active. In a new terminal, activate it again with `.venv\Scripts\Activate.ps1`
(Windows) or `source .venv/bin/activate` (macOS/Linux).

1. Start the simulator:
   ```
   python tests/tmflow_mock.py serve --sim
   ```
   It is ready when it prints `Listen1: Listen node waiting on 127.0.0.1:5890`. Leave this terminal
   open; **Ctrl+C** stops the simulator.
2. Open **http://127.0.0.1:8090/all** in your browser.
3. Pick the scenario **"Bench V1 v8: full assembly"** (`v8-full`) and press **Run**. Use
   `v8-full-fast` for a quicker run.
4. What you see on the page:
   - the robot moving in the 3D cell, with a progress bar per stage
   - the **Speed** slider, which changes the speed while the program runs
   - the **Collisions** panel at the top right of the 3D view, which lists every hit; colliding parts turn red
   - the **Manipulability** panel at the bottom left
   - the TMflow flow and the robot "conversation"

Other pages from the same simulator: http://127.0.0.1:8090/sim/ (the 3D cell only) and
http://127.0.0.1:8090/demo (the current step in plain words, for an audience).

## 4. Changing the program and checking it

The v8 program is generated by `bench_cell_v8.py` (the stages, grip points and heights are all in
there). After you edit it:

```
python bench_cell_v8.py                                    # rebuild the moves -> tests/v8_moves.json
python tests/robot_sim/cell_layout.py --cell v8            # only if you changed the cell/jig layout
python tests/robot_sim/collision.py tests/v8_moves.json --cell tests/robot_sim/cell_v8.glb --parts --list
```

Then press **Run** again on the page; you don't need to restart the simulator.
The collision check takes a few minutes. Add `--step 5` for a quicker, coarser check.
The other tools (reach, cycle time, TMflow export, teaching grip points) are described in
[tests/robot_sim/OWN_TOOL.md](tests/robot_sim/OWN_TOOL.md). Open questions and the current status
are in [Next steps.md](<Next steps.md>).

Before you commit, pull first (`git pull --rebase`). Other people push to this repo too.

## 5. Problems

| Problem | Fix |
|---|---|
| `python` not found (Windows) | Reinstall Python and tick "Add python.exe to PATH", or use `py` instead of `python`. |
| `python` not found (macOS) | Use `python3`. |
| `pip install python-fcl` fails | Use Python 3.11–3.13; it has ready-made wheels there. Without it the sim still runs, but the collision check and the red highlighting don't work. |
| `Address already in use` / port 8090, 5890 or 5891 busy | A simulator is already running (maybe in another terminal): stop it with Ctrl+C, or close that terminal. |
| The page loads but the 3D view stays empty | No internet (three.js comes from a CDN), or an ad blocker is blocking cdn.jsdelivr.net. |
| `ModuleNotFoundError` | The venv isn't active: activate it (see section 3) and run the command again. |
| You started it from the wrong folder (`No such file`) | `cd` into `3d-modeling-and-simulation/robot-cell` first. |

MMA4002 · TM5-900 · Listen-node bridge

Two ways to run the gripper from Python

The Python script can only move the robot while TMflow sits in a Listen node. The Hand-E only works through TMflow's own GRIP and RELEASE nodes. So every grip is a handover: the script leaves the Listen node, TMflow runs the gripper node, and the script reconnects. The two methods differ in who decides which gripper node comes next.

    This can't be generated as a file and imported. TMflow's project export is a password-protected zip, and RoboDK's Omron export only writes Point, SET and WaitFor nodes, never Listen, Gateway or Hand-E nodes. After building it, export it from TMflow to a USB stick (System → Import/Export) and keep that export in the repo, so it can be imported again on any TM robot.

What the mock and the scripts say

Port 5890 (Listen node) - the script asks, the robot answers:
$TMSCT
script command: TMscript lines (Line, PTP, QueueTag, var_x = …, ScriptExit) - this is what makes the robot move. Answer: OK, or ERROR;line.
$TMSTA 00
"are you in a Listen node?" - answer true/false and the node's name.
$TMSTA 01
"has QueueTag n finished?" - answer true (done), false (still moving) or none.
CPERR
protocol error: the packet itself was wrong (01 bad frame, 02 bad checksum, 03 unknown header, 04 bad data, F1 not in a Listen node).
Port 5891 (Ethernet Slave) - the robot talks, nobody answers:
$TMSVR
joint/pose stream: Joint_Angle and Coord_Robot_Flange, 50 times a second. This view gets the same numbers from the mock's /events.
